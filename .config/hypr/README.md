# DUNE — Arrakis at dusk

A Hyprland + Quickshell desktop themed after the film: thin ultra-wide tracked type, near-square
shapes, dusk-navy and spice-sand palette, the "eclipse flare" motif, slow heavy motion, and
procedurally synthesised sound effects.

## Pieces
- `hyprland.lua` — thin rotating "flare" border, 3px corners, warm long shadows, gritty sand-haze blur,
  cursor ripples through glass (`blur.water`) (window wobble is available as `decoration.wobble` but is off);
  slow "sandSettle / duneRise / haze / wind" animation curves.
- `hyprlock.conf` — GENERATED by `scripts/gen-hyprlock.py` (per-monitor sizing; laptop ×1.4). Cinematic title card: letterbox bars, huge thin clock, eclipse flare, *The sleeper must awaken*.
- `hypridle.conf` — dim 2.5 min → lock 5 → screen off 5.5 → suspend 15.
- `~/.config/quickshell/` — Dune bar (eclipse sigil, drifting workspace marker, centred tracked clock),
  `Eclipse.qml` motif, `Sandstorm.qml` (drifting sand behind windows, random gusts),
  `DuneIntro.qml` (login title card), `Sfx.qml`, `AppUsage.qml` (learns frequent apps → pinned row in the start menu; Alt+1…6, right-click to unpin); colours in `colors.json`.
- `sounds/gen.py` — synthesises `horn` (login), `thumper` (lock), `wind` (unlock), `notify`,
  `shift` (screenshot), `low` (critical / low battery). Re-run to regenerate.
- `scripts/lock` (thumper → hyprlock → wind), `scripts/sfx`, `scripts/screenshot`.
- Icons: Papirus-Dark (user-local in `~/.local/share/icons`) with sand (`brown`) folders.
- kitty `dune-theme.conf`, power menu `PowerMenu.qml` (replaces wlogout; reuses its line icons in `~/.config/wlogout/icons`), wofi, KDE/GTK colour scheme `Dune`.

## Keybindings
`Super` = the Windows key. **Hyper** = Caps Lock (`caps:hyper`, Mod3); press both Shifts for real Caps Lock.
Source of truth: `hyprland.lua` (search for `hl.bind` / `hb(`).
